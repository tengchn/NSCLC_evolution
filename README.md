# Data and Scripts

This repository contains the data and analysis scripts for our paper:

**Phylogenetic and phylodynamic approaches to understanding the evolution of non-small-cell lung cancer using single-cell sequencing**

Published in *Oncogene* (2026).

**DOI:** https://doi.org/10.1038/s41388-026-03997-1

## Citation

If you use the data or analysis scripts in this repository, please cite:

> Li T, Li X, Zou Y, Wong T, Campa M, Patz E, Rodrigo A. Phylogenetic and phylodynamic approaches to understanding the evolution of non-small-cell lung cancer using single-cell sequencing. *Oncogene*. 2026. https://doi.org/10.1038/s41388-026-03997-1
